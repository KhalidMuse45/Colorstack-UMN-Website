# Path ownership map

Who owns any path, how to claim new work, and how to extend a feature without
crossing an ownership boundary. Derived from [`README.md`](README.md) (§2, §5, §6),
[`../CONTRIBUTING.md`](../CONTRIBUTING.md), and
[`../design/ORCHESTRATION.md`](../design/ORCHESTRATION.md) — if this file and
those disagree, those win; fix this file.

## Owner classes

| Class | Meaning |
|---|---|
| **orchestrator-owned glue** | Shared files and mounting points. Only the orchestrator edits them — integration glue, conflict resolution, wiring. A slice that needs a change here escalates; it does not edit. |
| **slice-owned** | Written by the implementer holding the envelope whose write list names the path. Nobody else touches it while that slice is in flight. |
| **vendored-never-edit** | An upstream drop. Corrections go back through the source session and return as a new bundle. A local "fix" gets clobbered on the next pull. |
| **generated** | Produced by tooling. Never hand-edit. |

## The map

| Path | Class | Notes |

| `src/pages/` | slice-owned | New pages go here, per the page slices in `README.md` §3. |

## How to claim work

1. Slices 2–10 and their status are in [`README.md`](README.md) §3. One slice in
   flight at a time on the integration branch.
2. Work arrives as an **envelope** — copy [`envelopes/TEMPLATE.md`](envelopes/TEMPLATE.md),
   fill it in, one envelope per contributor or agent, never a second task in the
   same session.
3. The envelope's **FILES YOU MAY WRITE** list is the whole grant. Creating a
   sibling the plan names is allowed; editing anything outside the list is a
   violation and gets reverted ("I also fixed X" → X is reverted unless X was in
   the write list).

## Extension rules

- **New components go in `src/components/`.** New pages go in `src/pages/`.
- **One slice per branch:** `revamp/<slice-name>`. Parallel units within a slice
  work on **disjoint file sets** — never the same file.
- **Shared files are orchestrator-only:** `src/layouts/Base.astro`, `src/data/*`,
  `src/styles/*`, `package.json`. Need a change there? Escalate to the
  orchestrator; it lands as integration glue.
- **Missing token, missing data, missing asset:** escalate, don't invent. Leave
  the slot empty and log it in `HANDOFF-LOG.md` under `## Blocked`.
- **`design/` corrections** go through the design session
  (`design/PULL-FROM-DESIGN-CHAT.md`), never a local edit.
